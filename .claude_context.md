# VoiceForge — Claude context

## What this is
Voice cloning + long-form narration studio. Next.js on Vercel (free), TTS models on
free Colab T4 GPU exposed via Cloudflare tunnel. Zero cost, zero API keys.

## Hard constraints
- Vercel has NO GPU. Never put model inference in a Next.js route.
- Backend URL is user-supplied at runtime, never hardcoded, never an env var.
- Generation is SEQUENTIAL. One GPU. Never parallelize /generate calls.
- Every completed chunk writes to IndexedDB immediately. Disconnects must lose nothing.
- MAX_CHARS = 240 per chunk. This is load-bearing — longer chunks make both models drift.
- Qwen3 cloning requires ref_text (the sample transcript). Do not make it optional.
- `signal` orange (#FF6B4A) is ONLY for live/recording/generating. Never a button colour.

## Key files
- lib/chunker.ts    — script → chunks. Most important file. Change carefully.
- lib/normalize.ts  — number/abbreviation expansion. Runs before chunking.
- lib/backend.ts    — typed client for the Colab API.
- lib/audio.ts      — client-side stitch, gap insertion, peak normalize, WAV/MP3 encode.
- colab/voiceforge_server.ipynb — the GPU backend. Cannot be tested locally.

## Backend API
GET  /health   → { ok, gpu, models[], voices[] }
POST /clone    → multipart: audio, transcript → { voice_id, duration }
POST /generate → json: { text, voice_id, model, seed, ...params } → { audio_b64, sample_rate, duration }

## Defaults that took tuning — don't casually change
chatterbox: exaggeration 0.4, cfg 0.5, temperature 0.7
gaps: 0.35s sentence, 0.7s paragraph
export: peak normalize to -1 dBFS
